# 演示与使用说明（Demo Guide）

给两种情况用：**给别人演示**（面试、评审、展示）和**自己使用**（提问、看流程、查评估）。
命令都在仓库根目录 `langgraph-fullstack-python/` 下执行。

---

## 0. 三条启动路径，先选一条

| 路径 | 命令 | 需要什么 | 状态 |
|---|---|---|---|
| **A. 容器演示（推荐给演示场景）** | `docker compose -f deploy/docker-compose.dev.yml --env-file .env up -d` | Docker Desktop（Windows）/ Docker Engine（Linux）+ 已建索引 | 无许可要求；**状态在内存**，重启后会话清空 |
| **B. 本机开发运行** | `uv run langgraph dev --no-reload` | `uv sync` 完成 + `.env` | 最省事，热调试用 |
| **C. 官方生产运行时** | `docker compose -f docker/docker-compose.yml --env-file .env up -d` | **LangGraph 平台许可 或 LangSmith API Key** | 未获许可时容器会拒绝启动（见 §7） |

A 和 B 的功能**完全一样**（同一份代码、同一套认证/限额/RAG/UI）；差别只是运行形态。
无论哪条路径，浏览器都访问同一个地址：

```
http://127.0.0.1:8123     #A 路径（容器）
http://127.0.0.1:2024     #B 路径（开发服务器）
```

## 1. 演示前的 5 分钟准备

```bash
# 1) 环境变量（不要把这些值贴到任何文档或聊天里）
cp .env.example .env        # Windows: Copy-Item .env.example .env
#    必须设置：DEEPSEEK_API_KEY
#    可选设置：DEEPSEEK_MODEL=deepseek-flash
#             LANGGRAPH_DEMO_API_TOKEN=<random>   # 演示"共享令牌"时用
#             WEB_RATE_LIMIT_PER_MINUTE / WEB_RATE_LIMIT_PER_HOUR / WEB_MAX_INPUT_CHARS

# 2) 建索引（演示用的语料是项目自编测试材料，见 §6 的诚实声明）
uv run python scripts/index_knowledge.py \
    --knowledge-dir tests/fixtures/knowledge --rebuild

# 3) 启动
uv run langgraph dev --no-reload                 # 路径 B
# 或
docker compose -f deploy/docker-compose.dev.yml --env-file .env up -d   # 路径 A
```

**第一次检索会很慢**（BGE-M3 约 2.2 GB 权重惰性加载，本机实测 12–25 秒；容器内首次若还需下载则约 850 秒）。
演示前先"预热"，把这段时间挪走：

```bash
uv run python scripts/prewarm_rag.py                 # 路径 B
docker exec deploy-psychegraph-1 python scripts/prewarm_rag.py   # 路径 A（注意用 python，不是 uv run）
```

**健康检查**（演示前确认一次）：

```bash
curl http://127.0.0.1:8123/health
# {"status":"ok","graph_loaded":true,"vectorstore_available":true,"embedding_loaded":false}
```

`embedding_loaded:false` 是正常的（模型是惰性加载，"跑过一次之后"才变 true）。
`status:"degraded"` 说明索引没挂上——演示时回答会退化成"没有本地文献依据"，别在这时候演示引用功能。

## 2. 界面导览（演示时按这个顺序讲）

打开首页会自动跳到一条新会话。页面三栏：

1. **左栏 · 会话列表**：标题取自第一条用户消息（不额外调用模型，不花钱）。
2. **中栏 · 对话**：你的消息 → 一个"分析中"占位气泡 → 最终回答（带学派标签、质量行、可点击引用）。
3. **右栏 · 两个面板**
   - **Agent Workflow**：9 个节点（规划 / 证据 / 三个并行视角 / 综合 / 确定性检查 / 质量审核 / 完成），每个节点有状态、短说明和**真实耗时**；修订与保守回答节点平时显示"未触发"。
   - **Theory Evidence**：本轮检索到的段落，按学派分组，只显示索引里的元数据（标题/作者/章节/页码）。

细节（演示时可以顺口说）：

- 运行期间**输入框被禁用**，流结束后自动恢复；页面上**没有假的逐字打字效果**——结构化输出意味着答案只在最终节点后才存在，所以 UI 展示的是**流程进度**而不是伪装成 token 流。
- 引用标签 `[E1]`、`[E2]`… 点击会高亮右侧对应的证据卡片；标签映射来自最终结果的 `used_evidence_ids`。
- 页面上**永远不会出现**：草稿、审核意见、内部提示词、模型原始 JSON、服务器绝对路径。

## 3. 演示脚本（三条输入，覆盖全部卖点）

| # | 输入 | 你要指给观众看的东西 | 预期耗时 |
|---|---|---|---|
| 1 | `我梦见自己站在一扇打不开的门前，这说明什么？` | 三个学派**并行**各自执行（流程面板同时出现三个"进行中"）、证据面板按学派出现、回答里三个视角被综合、质量行显示审核结论 | 40–60 s |
| 2 | `从三个精神分析视角分析《哈姆雷特》的延宕。` | 规划节点先给出"分析任务"、综合回答里学说**互相区分**（不是三个同义句）、引用可点击 | 50–80 s |
| 3 | `我最近情绪很差，是不是抑郁症？给我个诊断吧。` | **临床边界**：系统不做诊断、给出一段简短说明而不是判断；这是安全设计，不是能力不足 | 30–50 s |

补充演示（按需）：

- **过程可信**：指着 Workflow 面板说"这是真实节点耗时，不是动画"。
- **引用诚实**：点开证据卡片，说明它引的是**本地检索到的段落**，且卡片上标着"项目自编测试材料"。
- **评估页**：访问 `/evaluation`，展示 60 用例 × 4 变体的消融结果（§5）。
- **运维面**：`/health`、限流 429、超长输入 413（§4）。

## 4. 功能验证清单（自己核对用，全部在本机可复现）

自动化版本（13 项，含真实模型回答）：

```bash
uv run python scripts/smoke_local.py --url http://127.0.0.1:8123 \
    --token "$LANGGRAPH_DEMO_API_TOKEN"      # 没设令牌就去掉 --token
```

手动版本（演示"防护"时逐条展示）：

| 项目 | 操作 | 预期 |
|---|---|---|
| 超长输入 | 粘贴 4001 个字符发送 | `413` + 中文提示气泡，不入队 |
| 并发限制 | 一条分析进行中再点发送 | `429` + "同时只能有一条分析在运行" |
| 限流 | 1 分钟内连发 7 次 | 第 7 次 `429`（默认每分钟 6 次） |
| 会话隔离 | 换一个浏览器（或无痕窗口）粘贴同一会话 URL | `404`"找不到这个会话" |
| 令牌保护 | `curl http://127.0.0.1:8123/threads` | `401`（设置了令牌时） |
| 本地静态资源 | F12 → Network | htmx / SSE 扩展来自 `/static/`，**无 CDN 请求** |
| 刷新恢复 | 跑完一轮后 F5 | 会话与最新回答（含引用）仍在（路径 A 容器重启除外） |
| 失败体验 | 临时把 `DEEPSEEK_API_KEY` 改成错误值再跑一轮 | 只有一句安全提示，无 traceback、无密钥 |
| 降级体验 | 把索引目录移走后重启 | `/health` → `degraded`，仍能回答但**不伪造引用** |

## 5. 评估页 `/evaluation` 怎么讲

- 数据来自 `docs/evaluation_summary.json`（聚合工件，由 `scripts/export_evaluation_summary.py` 生成），**页面本身不调用模型**。
- 4 个变体：Single Agent / Multi Agent / Multi Agent + RAG / Full System（含 Critic）。
- 关键结论（60 用例）：多代理把"理论区分度"从 3.92 提到 4.27，RAG 再提到 4.45 并让**引用有效率 = 1.00**，Critic 把总分略降(4.42)但换来质量兜底；临床拒答率四个变体都是 **1.00**。
- 指标是**工程指标**（引用可核验性、理论区分度、边界遵守、时延、token 成本），不是"理论正确性"。

## 6. 演示时必须说清楚的三件事（不要说反了）

1. **语料是自编测试材料。** `tests/fixtures/knowledge/` 是项目自编的测试语料（front matter 里带 `test_fixture: true`），页面上也标注"项目自编测试材料，不是 Freud / Klein / Lacan 原著数据库"。**不要因为它要展示给面试官就删掉这个声明。**
2. **不是临床工具。** 首页写明"用于理论学习、文本解释与文学/叙事分析，不用于临床诊断、心理治疗或医学建议"。不要用"AI 精神分析师/医生"这类描述。
3. **路径 A 是演示级部署，不是生产部署。** 它跑的是免费开发运行时：会话/检查点**在进程内存里**（重启即清空），不使用 PostgreSQL/Redis。官方生产运行时（路径 C）需要 LangGraph 平台许可。

另外口径：认证是"**演示级会话隔离 + 内部 API 共享令牌**"，不是用户账号系统。

## 7. 排障

| 现象 | 原因 | 处理 |
|---|---|---|
| 容器不断重启，日志含 `License verification failed` | 路径 C 的官方镜像需要许可 | 改用路径 A（`deploy/docker-compose.dev.yml`），或按 `docs/PRODUCTION_DEPLOYMENT.md` 第 6 节配置 LangSmith Key |
| `/health` 显示 `degraded` | 索引没建/没挂上 | 见 §1 第 2 步；容器路径要确认宿主 `data/vectorstore` 存在 |
| 第一次提问卡 20 秒以上 | BGE-M3 惰性加载 | 先跑 `prewarm_rag.py`（§1） |
| `docker build` 报 `dial tcp 127.0.0.1:443` | 本机 hosts 把 Docker 域名指到了本地 127.0.0.1，或构建没有代理 | 见 `docs/PRODUCTION_DEPLOYMENT.md` 的 "Local rehearsal gotchas" |
| 提示 429 | 触发限流/并发上限 | 等一会儿，或调 `.env` 的 `WEB_RATE_LIMIT_*` 后重启 |
| 换浏览器后打不开旧会话 | 会话归属绑定 cookie | 用原浏览器打开；这是设计行为 |
| 端口被占 | 已有实例在跑 | `docker compose -f deploy/docker-compose.dev.yml down` 或换 `--port` |

常用维护命令：

```bash
docker compose -f deploy/docker-compose.dev.yml down      # 停止（保留 HF 卷与索引）
docker compose -f deploy/docker-compose.dev.yml logs -f   # 看日志
docker volume ls | Select-String psychegraph-hf           # HF 权重卷（4.5 GB 左右）
uv run python scripts/index_knowledge.py --rebuild        # 重建索引（改语料后）
curl http://127.0.0.1:8123/health                         # 健康
```
